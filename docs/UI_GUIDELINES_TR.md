# UI/UX Rehberi (TR)

## Tasarim Prensipleri
- Basitlik: tek bakista okunabilir bilgi bloklari
- Dusuk gorsel yuk: minimum dikkat dagitici ogeler
- Cam benzeri (glassmorphic) ve yarisaydam kartlar
- Koyu ama kontrasti yuksek arka plan

## Pencere Modeli
1. Control Window
- Ayarlar, ses kaynagi secimi, oturum durumu, transcript/assist listesi

2. Overlay Window
- Sunum esnasinda ekrani az kaplayan kart
- EN transcript + TR ceviri + EN/TR cevap ozetleri

## Etkilesim Kurallari
- Ctrl+Shift+O: overlay goster/gizle
- Ctrl+Shift+M: cevap onerilerini sessize al/ac
- Ctrl+Shift+H: acil gizleme

## Tipografi ve Renk
- Font: Manrope (fallback Segoe UI)
- Accent: teal tonlari
- Kritik durumlar: soft red

## Mobil/Responsive Notu
V1 odagi masaustu olsa da pencere daraldiginda tek kolon layout otomatik devreye girer.
